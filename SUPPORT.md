# Support

Achilles is pre-alpha community software maintained on a best-effort basis.

## Where to ask

- Use [GitHub Discussions](https://github.com/Priyam1713/Achilles/discussions) for setup
  questions, design conversations and sharing benchmark results.
- Use [GitHub Issues](https://github.com/Priyam1713/Achilles/issues) for reproducible defects
  and scoped feature proposals.
- Use GitHub private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Before asking for help, run:

```powershell
uv run sovereign preflight
uv run python scripts/doctor.py --strict
```

Include the Achilles commit, operating system and WSL version, Python version, GPU/driver,
install profile, relevant logs with secrets removed, and the smallest reproduction you can
provide. Do not post tokens, credentials, private prompts, model licence acceptance records,
or personal workspace contents.

There is currently no guaranteed response time or paid support channel.
